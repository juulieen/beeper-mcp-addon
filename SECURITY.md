# Security

beeper-mcp-addon can read and send your messages, so security reports matter.

**Report a vulnerability privately**, not in a public issue: use GitHub's [private vulnerability reporting](https://github.com/juulieen/beeper-mcp-addon/security/advisories/new). You'll get an answer within a few days.

Fixes are released as a new version with a short "security fix" note; details are published in an advisory once users have had time to update. Only the latest version receives fixes: update with `npx -y beeper-mcp-addon@<latest version> install` (your assistant tells you when a new version is out).
